# Threat Model

Status: DRAFT

Model:
Assets -> trust boundaries -> adversaries -> attack surfaces -> abuse cases ->
controls -> tests -> evidence -> residual risk.

Include:
- unauthorized command
- credential compromise
- network spoofing/replay
- malformed industrial protocol traffic
- firmware substitution
- downgrade/rollback
- configuration tampering
- unsafe remote maintenance
- HMI privilege abuse
- historian/evidence tampering
- supply-chain substitution
- denial of service with safety/reliability impact
