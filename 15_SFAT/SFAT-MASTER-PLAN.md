# Software Factory Acceptance Test Master Plan

SFAT shall support execution without physical process hardware using governed
simulation and emulation where appropriate.

Coverage:
- nominal sequences
- boundary conditions
- invalid states
- permissives
- interlocks
- alarm behavior
- communication loss
- sensor faults
- actuator faults
- restart/recovery
- HMI commands/status
- historian/evidence
- cybersecurity negative tests where in scope
- regression after remediation

A software FAT PASS does not establish physical machinery conformity or
functional-safety certification.
