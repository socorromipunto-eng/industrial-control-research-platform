# ICRP Project Constitution

## Purpose
Create a provider-neutral, evidence-governed industrial control research
platform spanning machine/process control, industrial firmware, IEC 61131-3
control logic, SCADA/HMI, simulation, cybersecurity and validation.

## Independence boundary
ICRP is independent research. No third-party client code, NDA material,
proprietary PCNs, proprietary faceplates, or confidential implementation
artifacts may be copied into this repository.

## Canonical lifecycle
Memory -> Project Context -> Source of Truth -> Current Normative Baseline ->
Evidence -> Architecture -> Threat/Hazard Model -> Decision -> Authorization ->
Implementation -> Validation -> Adversarial Validation -> Independent Review ->
Promotion -> Continuous Assurance -> Documentation.

## Mandatory separations
- Law != standard
- Standard != harmonized standard
- Applicable != satisfied
- Tested != conformant
- Conformant != certified/validated
- Functional safety != cybersecurity
- Cybersecure != safe
- Safe control != CE conformity
- E-stop research logic != certified safety function
- Simulation != physical validation
- Draft != final authority
- UNKNOWN != TRUE

## Promotion rule
No architecture, hardware, firmware, control logic, HMI, safety function,
protocol, or compliance claim is promoted without a governed gate and evidence.
