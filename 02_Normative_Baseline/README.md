# Normative Baseline

The registry is discovery + governance metadata, not proof of applicability.

Rules:
1. Official source metadata is recorded before engineering mapping.
2. Copyrighted/licensed standards are not committed unless licensing permits it.
3. A newer draft never silently replaces a current published standard.
4. Harmonized/designated status is separately proven and time-bound.
5. EU and US requirements are mapped separately before crosswalk.
6. Crosswalk != legal equivalence.
7. Every normative update requires change-impact adjudication.
